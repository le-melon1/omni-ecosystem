# OmniRoute Smart Proxy (macOS)

Умный локальный прокси-оркестратор для связки **OmniRoute** с **Claude Code** и **OpenClaw** на Mac.

---

## 🖥️ Схема работы (Два окна):
Интерфейсы Claude Code и OpenClaw перехватывают вывод терминала.
Поэтому работа строится в 2 окна:
- **Окно 1 (Оркестратор и Мониторинг):** выводит живую статистику токенов, задержки и предупреждения о заменах.
- **Окно 2 (Claude / OpenClaw):** рабочее окно диалога с нейросетью.

---

## 🅰️ Вариант 1: Запуск для Claude Code

### Шаг 1: Запуск Оркестратора (Окно 1)
- **Способ через Finder:** Дважды кликните файл 👉 **`start_claude.command`**
- **Или через Терминал:**
  ```bash
  cd ~/Desktop/omni-mac
  ./start_claude.sh
  ```
Скрипт протестирует модели, выведет список работающих, предложит подтвердить или выбрать модели, запустит прокси и создаст файл `run_claude.sh`.

### Шаг 2: Запуск Claude Code (Окно 2)
Откройте вторую вкладку/окно терминала и выполните:
```bash
cd ~/Desktop/omni-mac
./run_claude.sh
```
*(Или просто выполните команду `claude`, предварительно скопировав переменные из первого окна).*

---

## 🅱️ Вариант 2: Запуск для OpenClaw

### Шаг 1: Запуск Оркестратора (Окно 1)
- **Способ через Finder:** Дважды кликните файл 👉 **`start_openclaw.command`**
- **Или через Терминал:**
  ```bash
  cd ~/Desktop/omni-mac
  ./start_openclaw.sh
  ```
Скрипт проверит модели, настроит `~/.openclaw/openclaw.json` и запустит мониторинг.

### Шаг 2: Запуск OpenClaw (Окно 2)
Откройте вторую вкладку/окно терминала и выполните:
```bash
openclaw chat
# или: openclaw tui
```

---

## 💡 Горячие команды в Окне 1:
- `c` + `Enter` — сменить модель на лету (показывает список и дает ввести номер).
- `s` + `Enter` — посмотреть текущие модели и сумму потраченных токенов.
- `r` + `Enter` — обновить файлы запуска для чистого перезапуска сессии.
- `q` + `Enter` — остановить прокси.
